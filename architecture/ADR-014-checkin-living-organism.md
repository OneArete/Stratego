# ADR-014 — Check-in Uses Living Graph, Not Symmetric SVG

**Status:** Accepted  
**Version:** 0.49.0  
**Date:** 2026-07-24

## Context

The check-in screen previously rendered a bespoke symmetric SVG (`renderSymmetricCheckinOrganism`) — six equal nodes arranged in a perfect hexagon, all identical. Alongside it, six dot indicators ("seeds", `.context-seed`) lit up sequentially as each signal was answered.

Two problems:

1. **One organism, two shapes.** Today used the Living Graph. Check-in used a different, static, structurally unrelated SVG. The person experienced two different visual languages for the same concept. Architecture visible to user.

2. **Seeds communicate nothing about the person.** A dot lighting up confirms an answer was registered. It does not reflect what the organism learned. After answering "significant soreness", the dot looked the same as after answering "excellent sleep". The organism was decorative, not communicative.

## Decision

Check-in now renders the same Living Graph as Today, driven by `buildCheckinGraph(context)`.

`buildCheckinGraph` computes a graph from partial context. Before any signal is answered, all six nodes are fully dormant (energy=0.14, confidence=0.07 — too low to distinguish in the renderer, producing a symmetric, dim shape). As each signal is answered, its canonical domain awakens:

- `sleep` answered → Recovery node lights up
- `energy` answered → Body node lights up  
- `time` answered → Agency node lights up
- etc.

The organism progressively comes alive during the check-in. By the time the last signal is answered, the organism already reflects the person's full context — the same organism the person will see on Today.

The symmetric SVG and seed dots are removed entirely.

## Consequences

- One organism. Same renderer, same visual language, across check-in and Today.
- The organism communicates before any text — each answer physically changes the organism.
- `renderSymmetricCheckinOrganism()` is retained in code (still declared) but is no longer called from `checkin()`.
- CSS classes `.checkin-organism`, `.checkin-node-*`, `.context-seed` remain in `styles.css` for backward compatibility but are no longer generated by the app.
- Tests updated: `invisible-organism-phase-1.test.js` and `experience-rewrite.test.js` now assert Living Graph presence, not seed presence.
