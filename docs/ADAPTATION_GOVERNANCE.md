# Strategos — Adaptation Governance

Status: frozen with v0.18.10  
Scope: Practice adaptation only

## Governing principle

```text
Strategos advises.
The person decides.
The system preserves what actually happened.
```

## Precedence

```text
1. Current safety
2. Explicit person choice in the current phase
3. Healthy confirmed adaptation default
4. Contextual guidance for today
5. Standard technique fallback
```

No lower layer may override a higher layer.

## Evidence lifecycle

```text
person chooses a version
→ reflection assesses fit
→ repeated comparable choices form a candidate
→ person confirms or rejects
→ confirmed pattern may set the initial version
→ real outcomes continuously audit that default
→ repeated worse outcomes pause automatic use
→ person may reject or return it to candidate
→ fresh evidence is required before reconfirmation
```

## Boundaries

An adaptation pattern:

- never selects the Practice;
- never changes the judgement;
- never changes judgement confidence;
- is scoped to the same Practice, phase and adaptation level;
- remains subordinate to current safety;
- remains reversible by the person;
- retains complete provenance in Journey and Audit.

## Required evidence

Initial candidate:

```text
3 supportive comparable sessions
within 180 days
same Practice
same phase
same level
```

Reconfirmation after reopening:

```text
2 new supportive person-directed uses
after reopening
same Practice
same phase
same level
```

Automatic confirmed-default uses do not count as fresh reconfirmation evidence.

## Frozen interaction rules

- `Easier / Standard / Harder` changes the current phase only.
- Changing level does not reset the timer or reroute the Practice.
- The reflection asks about adaptation fit only when an adaptation was used.
- Journey distinguishes system default from person choice.
- Understanding → Agency governs patterns.
- Understanding → Audit preserves the full lineage.
- Browser-native prompts are not used for alternative Practice choice.
