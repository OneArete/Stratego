# Morning Experience Governance

The Morning Experience is the focused entry point to each Daily Story.

It may expose only three states: incomplete context, ready for Agora, or an existing current judgement. It does not create a judgement, infer missing signals, or hide the person’s ability to revise context.

Complexity is progressively disclosed. The full daily signal controls remain available in Today, while the primary surface presents one next action and a concise explanation.
