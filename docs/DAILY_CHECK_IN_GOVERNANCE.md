# Daily Check-in Governance

## Purpose
The Daily Check-in makes Today reusable in ordinary life. A person's explicit signal selections are retained for the current local calendar day and remain editable.

## Rules
- One check-in per local calendar day.
- Every change is person-selected and saved locally.
- The check-in is descriptive context, not a diagnosis.
- Previous days are never silently overwritten.
- Reset removes only the current day's check-in.
- Daily signals may inform the current Agora because the person explicitly supplied them; they do not independently create beliefs or character claims.
