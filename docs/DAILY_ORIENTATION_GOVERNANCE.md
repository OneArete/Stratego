# Daily Orientation Governance — v0.32.0

Daily Orientation is a deterministic, descriptive synthesis of person-entered daily signals.

## Boundaries
- It is not a judgement, diagnosis or recommendation.
- It cannot start a Practice or choose a Practice.
- Personal Evidence may be displayed only after the existing repetition threshold.
- Personal Evidence influence remains 0.
- The Agora remains the only deliberative recommendation path.
- Recent Daily Rhythm is descriptive and never creates beliefs automatically.

## Purpose
Make Today immediately intelligible while preserving deliberation, autonomy and epistemic humility.
