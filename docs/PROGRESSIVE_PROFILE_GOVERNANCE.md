# Progressive Profile Governance

The profile is person-declared context, not an inferred identity.

1. Every field beyond name is optional.
2. Invalid values are discarded rather than guessed.
3. Limitations are stored as person-written text and are not diagnostically interpreted.
4. The person can review and change the profile at any time.
5. Profile changes are reconciled into the Human Model transparently.
6. No profile field may silently create a judgement, Practice choice or safety conclusion.
