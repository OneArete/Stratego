# Strategos v0.66.0 — First Experience

## Objective
A person opening Strategos for the first time must understand what it is before being asked for daily evidence.

## Changed
- Replaced the previous feature-led onboarding with a four-moment first experience.
- Explains the problem: abundant knowledge does not remove the difficulty of situated judgement.
- Explains the product in human language: understand the moment, receive one direction, preserve human choice.
- Introduces the one-moment / one-decision / one-next-step experience model without exposing architecture.
- Keeps onboarding progressive: only the person’s name is requested before the first daily understanding flow.
- Updated release token, package identity, Service Worker cache and in-app What’s New entry.

## Preserved
- Premium visual language and Living Organism.
- Today, Current Moment, Evidence Gate, Ágora and Current Judgement behavior.
- Commitment and Begin Practice flow from v0.65.0.
- Practice voice, sound, haptics, wake lock and local-first persistence.

Run `npm test` from the repository root.
