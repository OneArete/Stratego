# Strategos v0.67.0 — Practice Experience

## Changed

- Rebuilt the active Practice surface as a full-height, distraction-free experience.
- Reduced visible execution language to the phase, timer, one primary cue and quiet progress.
- Replaced the prominent next-phase card with a subordinate transition hint.
- Preserved technique, adaptation and safety details behind progressive disclosure.
- Added a dedicated Practice-complete moment before Reflection.
- Preserved pause, previous/next phase, safety interruption, voice, sound, haptics and Wake Lock.

## Removed

- Immediate transition from the final Practice second into Reflection questions.
- Duplicate total-progress presentation inside the execution body.
- Excess visual weight around upcoming phases.
